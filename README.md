## 2025：顺丰 Web 自动化测试

### 1. 项目介绍

本项目以顺丰速运官方网站（https://www.sf-express.com/）为测试对象，针对官网服务支持模块开展 Web 自动化测试。

通过 Python 编程语言，结合 Selenium 浏览器自动化技术和 Pytest 测试框架，实现网页功能的自动化操作、测试用例执行、测试结果验证及异常截图保存。

项目围绕实际业务需求设计测试场景，旨在验证网站核心功能的正确性、稳定性及页面交互行为。

### 2. 测试范围

本项目主要覆盖以下四大核心功能模块：

| 测试模块 | 测试内容 |
|---|---|
| 运费时效查询 | 不同寄件地区、收件地区及货物参数下的运费与时效查询 |
| 服务网点查询 | 网点地址选择、区域筛选及网点信息查询 |
| 收寄标准查询 | 不同货物条件下的收寄标准查询 |
| 服务范围查询 | 不同地区服务范围及相关信息查询 |

项目按照需求编号组织测试，共包含 R001—R010 共 10 项需求，对应设计了 27 条测试用例。

### 3. 技术栈

| 技术 | 用途 |
|---|---|
| Python 3.12 | 自动化测试脚本开发 |
| Selenium | 浏览器自动化操作 |
| Pytest | 测试用例组织、执行及结果管理 |
| Chrome / ChromeDriver | 浏览器驱动与页面交互 |
| VS Code | 项目开发与调试 |

### 5. 环境配置

运行项目前，请确保本机已安装：

- Python 3.12 或兼容版本
- Google Chrome 浏览器
- 与 Chrome 浏览器版本兼容的 ChromeDriver

安装项目依赖：

```bash
pip install selenium pytest
```

同时需要检查测试脚本中的 ChromeDriver 配置路径，确保其与本机实际安装位置一致。

### 6. 运行测试

进入项目目录：

```bash
cd "2025顺丰web自动化测试"
```

执行全部自动化测试用例：

```bash
pytest -v -s test_SF.py
```

执行指定测试用例，例如 R006：

```bash
pytest -v -s test_SF.py::TestSF::test_SF_R006
```

执行指定需求对应的其他测试时，将最后的测试函数名称替换为对应的 R001—R010 即可。

### 7. 测试结果与截图

项目通过 Pytest 执行测试用例，并在终端输出测试执行情况，包括：

- 测试用例执行结果
- 测试通过与失败情况
- 异常信息及错误定位
- 测试执行过程中的相关日志

测试过程截图统一保存在 `screenshots` 文件夹中，截图文件采用时间戳与测试用例编号组合的命名方式，例如：

```text
时间戳_SF_R001_001.png
```

便于后续进行测试结果核对、问题追踪及竞赛材料整理。

### 8. 项目说明

1. 自动化测试依赖目标网站的实际运行状态及网络环境，建议在稳定的网络环境下执行。
2. 网站页面结构或元素定位方式发生变化时，可能需要同步调整 Selenium 定位器。
3. 执行测试前应确认 ChromeDriver 与 Chrome 浏览器版本兼容。
4. 测试结果以实际运行情况为准，截图及执行日志可作为辅助验证材料。
