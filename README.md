## 2025：顺丰 Web 自动化测试

### 1. 项目介绍

本项目以[顺丰速运官方网站](https://www.sf-express.com/)为测试对象，针对官网服务支持模块开展 Web 自动化测试。

使用 Python、Selenium 和 Pytest 实现网页自动化操作、测试用例执行、结果验证及异常截图保存，验证网站核心功能的正确性与稳定性。

### 2. 测试范围

主要覆盖以下四大核心功能模块：

| 测试模块 | 测试内容 |
|---|---|
| 运费时效查询 | 不同寄收地区及货物参数下的运费与时效查询 |
| 服务网点查询 | 网点地址选择、区域筛选及网点信息查询 |
| 收寄标准查询 | 不同货物条件下的收寄标准查询 |
| 服务范围查询 | 不同地区服务范围及相关信息查询 |

项目按照需求编号组织测试，包含 R001—R010 共 10 项需求，对应设计 27 条测试用例。

### 3. 技术栈

| 技术 | 用途 |
|---|---|
| Python | 自动化测试脚本开发 |
| Selenium | 浏览器自动化与页面交互 |
| Pytest | 测试用例组织、执行与断言 |
| Chrome / ChromeDriver | 浏览器驱动与测试执行 |
| VS Code | 开发与调试 |

### 4. 项目结构

```text
2025顺丰web自动化测试/
├── test_SF.py           # 自动化测试主脚本
├── screenshots/         # 测试过程截图
└── 其他测试资料         # 测试用例及相关文档
```

## 2026：UU 工具编辑器自动化测试

### 1. 项目介绍

本项目以 UU 工具编辑器为测试对象，根据项目需求文档开展 Web 功能自动化测试。

使用 Python、Selenium 和 Pytest 编写自动化测试脚本，实现页面元素定位、用户操作模拟、测试结果断言及测试截图保存，提高测试执行效率与测试过程的可重复性。

### 2. 测试范围

围绕 UU 工具编辑器的功能需求，设计并执行自动化测试用例，主要包括：

| 测试内容 | 测试说明 |
|---|---|
| 页面交互测试 | 验证页面控件及交互操作是否符合预期 |
| 功能流程测试 | 按照需求文档验证相关业务操作流程 |
| 输入与异常场景测试 | 验证不同输入条件下的功能表现 |
| 测试结果验证 | 通过断言及测试截图检查实际结果 |

测试脚本按照需求编号组织，便于独立执行、问题定位与后续维护。

### 3. 技术栈

| 技术 | 用途 |
|---|---|
| Python | 自动化测试脚本开发 |
| Selenium | 页面元素定位与浏览器操作 |
| Pytest | 测试用例管理、执行与断言 |
| Chrome / ChromeDriver | 浏览器自动化测试环境 |
| VS Code | 开发与调试 |

```text
2026UU工具编辑器自动化测试/

└── screenshots/         # 测试执行截图
```
